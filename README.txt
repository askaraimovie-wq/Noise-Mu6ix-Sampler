Noise Mu6ix Sampler - Flat Root Layout (GitHub Auto-Build)
===========================================================

எல்லா மெயின் ஃபைல்களும் (`CMakeLists.txt`, `VERSION.txt`, `PluginProcessor.h`, `PluginProcessor.cpp`, `PluginEditor.h`, `PluginEditor.cpp`) நேரடியாக வெளியே (Root-ல்) வைக்கப்பட்டுள்ளன.

1. GitHub Repository-ல் "Add file -> Upload files" கொடுத்து இந்த ஃபைல்களை நேரடியாக அப்லோட் செய்யலாம்.
2. GitHub Actions தானாக Windows VST3 ஃபைலை உருவாக்கும்.
3. அடுத்த வெர்ஷனுக்கு `VERSION.txt` ஃபைலில் உள்ள நம்பரை மட்டும் மாற்றினால் போதும்.
